# Math-notes

Mathematics notes in LaTeX, with complete proofs.

```
Math-notes/
├── Real analysis/    cardinality, the real line, metric spaces, compactness, convexity, separation
├── Linear algebra/   from vector spaces to SVD and PCA, LU/QR, k-means and gradient descent
└── Measure theory/   from Riemann to Lebesgue, martingales, Itô and Black-Scholes
```

Each folder has the notes (`.tex` and compiled `.pdf`) and the original Spanish PDF with the `(es)` suffix; Linear algebra also has its Python implementations.
